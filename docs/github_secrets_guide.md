## Пошаговая инструкция по созданию секретов на GitHub

Вам нужно будет повторить этот процесс три раза для трех разных секретов. Это необходимо, чтобы GitHub Actions мог безопасно подключаться к вашему хостингу Reg.ru и автоматически выкладывать сайт.

---

### Шаг 1: Перейдите в настройки репозитория

1.  Откройте ваш репозиторий в браузере по ссылке:
    [https://github.com/merkulovid-ux/retrospective](https://github.com/merkulovid-ux/retrospective)

2.  Над списком файлов найдите и нажмите на вкладку **Settings** (иконка с шестеренкой).

    *Иллюстрация:*
    ![Шаг 1: Вкладка Settings](https://i.imgur.com/a7bB8hR.png)

---

### Шаг 2: Перейдите в раздел "Actions secrets"

1.  В меню настроек, которое откроется слева, найдите раздел **Secrets and variables**.
2.  В раскрывшемся подменю выберите пункт **Actions**.

    *Иллюстрация:*
    ![Шаг 2: Меню Secrets and variables -> Actions](https://i.imgur.com/iY3v3zL.png)

---

### Шаг 3: Создайте новый секрет

1.  На открывшейся странице вы увидите секцию "Repository secrets".
2.  Нажмите на зеленую кнопку **New repository secret**.

    *Иллюстрация:*
    ![Шаг 3: Кнопка New repository secret](https://i.imgur.com/A2gO1pW.png)

---

### Шаг 4: Заполните данные для первого секрета (`FTP_SERVER`)

1.  **Name (Имя):**
    *   В это поле введите **точно** так, как здесь написано (большими буквами):
      ```
      FTP_SERVER
      ```

2.  **Secret (Значение):**
    *   В это большое текстовое поле вставьте **адрес вашего FTP-сервера**, который вы нашли в панели управления Reg.ru (например, `sXXXX.reg.ru` или `ftp.reg.ru`).

3.  Нажмите зеленую кнопку **Add secret**.

    *Иллюстрация:*
    ![Шаг 4: Заполнение полей для секрета](https://i.imgur.com/O3gG2qF.png)

---

### Шаг 5: Повторите для остальных секретов

Теперь вернитесь на страницу "Actions secrets" и повторите **Шаг 3** и **Шаг 4** еще два раза для оставшихся данных:

*   **Второй секрет:**
    *   **Name:** `FTP_USERNAME`
    *   **Secret:** Ваш FTP-логин из панели Reg.ru.

*   **Третий секрет:**
    *   **Name:** `FTP_PASSWORD`
    *   **Secret:** Ваш FTP-пароль.

---

### Результат

После выполнения всех шагов у вас в списке "Repository secrets" должно появиться три секрета: `FTP_SERVER`, `FTP_USERNAME` и `FTP_PASSWORD`.

Как только вы их создадите, GitHub Actions автоматически получит к ним доступ и сможет выполнить развертывание вашего сайта на хостинг. Вы можете зайти на вкладку **Actions** в вашем репозитории, чтобы увидеть статус выполнения.
