# План Спринта 11

**Цель:** Устранить блокеры, мешающие релизу, и погасить технический долг, выявленный в Спринте 10.

**Бэклог Спринта:**

*   **P0 - Критический блокер:**
    *   `S11-001 (DevOps)`: Починить окружение для запуска E2E-тестов в CI/CD.
        *   *Критерий приемки:* E2E-тесты успешно и стабильно выполняются при каждом Pull Request.

*   **P1 - Технический долг:**
    *   `S11-002 (FE)`: Провести рефакторинг виджета "Симулятор Ретроспектив", вынеся его конфигурацию в отдельный JSON-файл.
        *   *Критерий приемки:* Логика виджета упрощена, конфигурация форматов загружается из внешнего JSON-файла.

*   **P2 - Улучшения:**
    *   `S11-003 (UX/FE)`: Добавить кнопку "Назад" в интерфейс виджета.
        *   *Критерий приемки:* Пользователь может вернуться с шага выбора формата к предыдущему состоянию.
    *   `S11-004 (AN/FE)`: Добавить `sessionId` в события аналитики для виджета.
        *   *Критерий приемки:* Параметр `sessionId` присутствует во всех событиях, связанных с виджетом.
    *   `S11-005 (UX/FE)`: Сделать выравнивание контента в форме виджета по левому краю.
        *   *Критерий приемки:* Все элементы внутри формы виджета (заголовки, текст, поля ввода) выровнены по левому краю.
