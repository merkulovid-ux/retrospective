# План реализации задачи S19-002

### Задача: Реализация ИИ-виджета (Вариант А) с механизмами защиты на основе утвержденной архитектуры.

---

### Участвующие роли:
*   **Frontend Engineer (FE):** Реализует всю клиентскую логику.
*   **DevOps Engineer:** Создает и настраивает serverless-функцию.
*   **QA Lead (QA):** Тестирует весь новый функционал.

---

### Что будет сделано:

**Часть 1: Бэкенд (DevOps)**
1.  Выбрать платформу для serverless-функции (например, Vercel или Netlify, так как они хорошо интегрируются со статичными сайтами).
2.  Создать новую serverless-функцию (например, `api/analyze.js`).
3.  Реализовать в ней логику Rate Limiting по IP-адресу.
4.  Реализовать логику обращения к API Google reCAPTCHA для верификации токена.
5.  Реализовать логику обращения к API Gemini (LLM), используя API-ключ, который будет храниться в секретах окружения.
6.  Настроить CI/CD для автоматического развертывания этой функции.

**Часть 2: Фронтенд (FE)**
1.  Добавить в `index.html` скрипт Google reCAPTCHA v3.
2.  Модифицировать JS-код виджета: после того, как пользователь вводит текст, появляется кнопка "Анализ с ИИ".
3.  При клике на эту кнопку:
    *   Добавляется простое поле-ловушка (honeypot) в DOM (как дополнительный уровень защиты).
    *   Кнопка "Анализ с ИИ" становится неактивной (клиентский таймаут).
    *   Запускается reCAPTCHA для получения токена.
    *   Если поле-ловушка не заполнено, отправляется fetch-запрос на наш бэкенд (`/api/analyze`) с текстом пользователя и токеном.
    *   Во время ожидания ответа в виджете отображается индикатор загрузки (спиннер).
    *   После получения ответа он отображается в секции "summary". В случае ошибки — выводится соответствующее сообщение.

**Часть 3: Тестирование (QA)**
1.  Провести ручное тестирование всего сценария.
2.  Написать E2E-тесты (Playwright), которые будут "мокать" (имитировать) ответ от бэкенда `/api/analyze`, чтобы проверить корректность работы UI (отображение спиннера, результата, ошибки) без реального вызова ИИ в тестах.

---

### Образ результата:

В виджете появится кнопка "Анализ с ИИ". При нажатии на нее пользователь увидит индикатор загрузки, а затем — сгенерированный ИИ план по улучшению на основе его текста. Функция будет защищена от ботов и флуда. Весь флоу будет покрыт тестами.
