# Отчет по аудиту Mobile-first и доступности (a11y) — S16-008

---

### Общий результат:

Лендинг имеет очень хорошую базу в плане адаптивности и доступности, но была найдена одна критическая проблема, связанная с контрастностью цветов, которая нарушает стандарт WCAG 2.2 AA.

---

### Найденные проблемы и рекомендации:

**1. Недостаточная контрастность основного акцентного цвета (Критичность: Высокая)**

*   **Проблема:** Основной акцентный цвет `#FF6F00` (переменная `--color-accent-primary`), используемый для ссылок, имеет коэффициент контрастности ~3.0:1 на светлом фоне (`#F8F8F8`). Это не соответствует минимальному требованию WCAG AA в 4.5:1 для текста нормального размера.
*   **Влияние:** Пользователи с нарушениями зрения могут испытывать трудности при чтении текста ссылок.
*   **Рекомендация:** Заменить значение переменной `--color-accent-primary` на более темный оттенок оранжевого, который соответствует требованиям. Например, цвет `#D85D00` обеспечивает коэффициент контрастности ~4.55:1. Это изменение нужно внести в одно место (в `:root`), и оно автоматически применится ко всем элементам.

---

### Положительные моменты (что уже сделано хорошо):

*   **Адаптивность (Mobile-First):** Сайт отлично спроектирован для мобильных устройств. Использование `clamp()` для шрифтов и гибких гридов обеспечивает корректное отображение на всех экранах.
*   **Семантика:** HTML-структура использует семантические теги (`main`, `section`, `nav` и т.д.), что улучшает доступность для скринридеров.
*   **Доступность с клавиатуры:** Реализован механизм "skip-link" для быстрого перехода к основному контенту. Все интерактивные элементы имеют четко видимые стили фокуса (`:focus-visible`).
*   **ARIA-атрибуты:** Корректно используются ARIA-роли и атрибуты для улучшения доступности сложных виджетов, таких как мобильное меню и cookie-баннер.
*   **Альтернативный текст:** Все изображения имеют осмысленные `alt` атрибуты.
*   **Производительность:** Базовые показатели производительности в норме: скрипты не блокируют рендеринг, изображения загружаются асинхронно.
