# План и образ результата для задачи S18-001

### Задача: Восстановить интерактивную логику виджета "Мини-ретро"

---

### Участвующие роли:
*   **Frontend Engineer (FE):** Восстанавливает JS-код и HTML-структуру виджета.
*   **QA Lead (QA):** Восстанавливает тесты и адаптирует их для стабильной работы.
*   **DevOps Engineer (DevOps):** Помогает в настройке CI-среды для проверки гипотез о падении тестов.

---

### Что будет сделано:

1.  **(FE) Восстановление кода:** Я найду в истории Git и восстановлю версию `index.html` с интерактивным JS-кодом виджета и первоначальной HTML-структурой (с кнопками выбора формата).
2.  **(QA) Восстановление тестов:** Я восстановлю из истории Git файл `tests/widget.spec.ts` с набором тестов для интерактивного виджета.
3.  **(QA/DevOps) Проверка гипотез:** Мы начнем планомерную проверку гипотез из отчета `S16-010_research_report.md`. **Начнем с Гипотезы 2 (Проблема с асинхронностью/таймингами)**, так как она наиболее вероятна. QA обновит тесты, добавив в них более надежные методы ожидания (`waitForFunction`, `waitForSelector` с нужным состоянием), а DevOps подготовит среду для их запуска.

---

### Образ результата:

Виджет на лендинге снова станет интерактивным: пользователь будет видеть выбор из трех техник, а затем пошагово проходить выбранный сценарий. Пользовательский опыт будет восстановлен до первоначального, более вовлекающего варианта. **Ключевой результат:** Тесты для этого интерактивного виджета будут стабильно проходить в CI-окружении, что устранит технический долг и позволит в будущем безбоязненно развивать интерактивные фичи.
