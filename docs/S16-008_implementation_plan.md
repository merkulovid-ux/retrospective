# План и образ результата для исправления по аудиту (S16-008)

---

### Что будет сделано:

1.  Я немедленно реализую единственную критическую рекомендацию из отчета по аудиту.
2.  Я найду в `index.html` CSS-переменную `--color-accent-primary`.
3.  Я заменю ее текущее значение `#FF6F00` на рекомендованное, соответствующее стандарту WCAG AA: `#D85D00`.
4.  Это изменение будет применено ко всем элементам, использующим этот цвет, автоматически решая проблему контрастности на всем сайте.

---

### Образ результата:

Все оранжевые текстовые элементы (в основном, ссылки) на сайте станут немного темнее. Лендинг будет полностью соответствовать требованиям контрастности WCAG 2.2 AA, что сделает его доступным для пользователей с нарушениями зрения. Проблема, выявленная в ходе аудита, будет не просто задокументирована, а немедленно устранена, повышая качество продукта прямо сейчас.
