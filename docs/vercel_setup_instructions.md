# Инструкции по настройке проекта Vercel

### 1. Framework Preset (Шаблон фреймворка):
*   **Что выбрать:** Выберите **`Other`**.
*   **Почему:** Это правильный выбор, так как у нас нет специфического фреймворка (вроде Next.js или React), а просто набор HTML/CSS/JS файлов.

### 2. Root Directory (Корневая директория):
*   **Что выбрать:** **Оставьте это поле без изменений.**
*   **Почему:** Ваш проект (`index.html`, папка `api` и т.д.) находится в корне репозитория, поэтому Vercel уже правильно определил его местоположение. Здесь ничего менять не нужно.

---

**Напоминание:** Не забудьте про **"Build and Output Settings"**, как я упоминал ранее: **"Build Command"** должен быть пустым, а **"Output Directory"** — отключен.
