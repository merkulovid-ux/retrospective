# Tone of Voice — Stop / Allow

Цель: единый стиль коммуникаций. Stop — избегаем; Allow — используем.

## Stop
- Маркетинговые гиперболы без фактов: «лучший», «революционный»
- Пассивные формулировки и канцелярит
- Агрессивные CTA: «Купи сейчас или упустишь шанс»
- Триггерные формулировки без контекста (security/privacy)

## Allow
- Ясные, конкретные выгоды и факты
- Нейтрально‑доброжелательный тон; краткость
- Прозрачные условия, ссылки на политику/оферту
- Инклюзивный язык, уважение к ограничениям (a11y)

## Примеры
- Stop: «Мы лучшие на рынке!» → Allow: «Сокращаем время подготовки ретро на 30% по данным пилота»
- Stop: «Нужно сделать…» → Allow: «Предлагаем следующий шаг…»
